# Product Context: MCP Weather Server

The MCP Weather Server exists to provide seamless access to reliable weather data through the Model Context Protocol. It solves the problem of integrating weather information into MCP-enabled applications without requiring direct API management by the client.

Users of this server expect:
- Fast and accurate current weather data for any city worldwide.
- A 10-day forecast to assist in planning and decision-making.
- Flexible unit options (metric, imperial, or both) to suit diverse user preferences.
- Robust error handling to gracefully manage invalid inputs or API issues.
- Easy deployment and integration via Docker containers.

The user experience goal is to make weather data retrieval as simple and reliable as possible within the MCP ecosystem, enabling developers to focus on their core applications.
